# Structure Constraints

- Use MECE structure for categories, plans, issue breakdowns, diagrams, and option sets.
- Make buckets mutually exclusive, with no overlapping categories.
- Make buckets collectively exhaustive, with no missing relevant cases.
- If the structure cannot be fully MECE yet, name the unknowns or create an explicit `Other / unresolved` bucket.
- Prefer links and references over duplicating the same content in multiple places.
