# Source Inspirations

This kit is shaped by practical patterns from Eve's projects and notes.

## Exemplary Claude

The gist `EXEMPLARY-CLAUDE.md` provides the baseline coding-agent rules: small changes, match style, verify, avoid secrets, and keep writing direct.

## Grill With Docs

Matt Pocock's `grill-with-docs` skill inspired the interrogation pattern: ask sharp questions, check code and docs, clarify language, and preserve only useful decisions.

Source:

- `https://github.com/mattpocock/skills/tree/main/skills/engineering/grill-with-docs`

## Dataset Scout

`dataset-scout` inspired the recon-report pattern: produce reports with receipts, make coverage gaps explicit, and support both readable and audit-friendly outputs.

## Prompt Garden

Prompt Garden inspired the prompt-library maintenance skill: prompt suffixes, reusable prompts, backlog capture, import/export, and cross-device sync.

## Second Brain

The second-brain vault inspired the raw-to-curated approach: preserve source material, synthesize durable pages, and avoid pretending first-pass filing is perfect.
