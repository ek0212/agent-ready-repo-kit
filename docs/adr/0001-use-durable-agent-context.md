# Use Durable Agent Context

Agent context in this repo should preserve stable constraints, conventions, verification commands, and repeated mistakes to avoid. It should not preserve volatile implementation summaries or current feature status.

## Status

accepted

## Consequences

- Agent instructions stay shorter and more likely to be followed.
- Some details must be rediscovered from code instead of cached in docs.
- Diagrams, `CONTEXT.md`, and ADRs carry context that does not belong in `AGENTS.md`.
