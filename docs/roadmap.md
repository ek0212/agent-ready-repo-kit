# Roadmap

## Next Good Additions

- Add a one-command installer that copies selected templates into a target repo.
- Add example `AGENTS.md` files for Eve's project types:
  - prompt library app
  - AI research pipeline
  - Chrome extension
  - VS Code extension
  - static report generator
- Add an HTML demo report for `docs-grounded-recon-report`.
- Add a small checklist runner script that verifies all skills have frontmatter.
- Add a public landing README with screenshots of diagrams and before/after examples.

## Possible Publish Shape

First public release:

- 10-15 skills
- 5-6 templates
- one before/after example
- one Mermaid system map
- clear install and copy instructions

Avoid building a package manager too early. The first useful version is just Markdown people can copy.
