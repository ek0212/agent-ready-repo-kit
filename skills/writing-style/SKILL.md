# Writing Style

## When To Invoke This Skill

- When writing or editing Markdown, comments, docs, summaries, reports, or PR text.
- When generating an `AGENTS.md` template that should carry Eve's writing style.
- Before publishing user-facing explanatory text.

## Inputs

- Draft text.
- Intended audience.
- Any source material or claims that need citation.

## Procedure

### Step 1: Make It Direct

Be direct and concise. State assumptions and limitations clearly.

### Step 2: Use Plain English

Avoid overcomplicated explanations, excessive specifics, and deep jargon unless the audience requires it.

### Step 3: Remove Banned Patterns

Remove:

- "This isn't X. It's Y." contrast patterns.
- Self-answering rhetorical questions.
- Em-dashes.
- Three-part alliterative phrases.
- Vague inspirational pivots.
- Unsourced claims or unverified quotes.

### Step 4: Check Claims

If a claim is factual, cite a source or mark it as an inference. Do not dress guesses as facts.

### Step 5: Verify Tone

The final text should sound clear, useful, and grounded, not inflated.

## Outputs

- Cleaned prose.
- Notes on any claims that still need sources.
